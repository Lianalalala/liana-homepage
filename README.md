# Liana Homepage

Personal website built with **React + Vite + Tailwind CSS**, deployed via **GitHub Pages**.

## Live Site
https://lianalalala.github.io/liana-homepage/

## Features
- Single-page layout: Hero / About / Projects / Experiences / Contact
- Responsive design (mobile-friendly)
- Project cards with images

## Tech Stack
- React
- Vite
- Tailwind CSS
- GitHub Actions + GitHub Pages

## Local Development
```bash
npm install
npm run dev
